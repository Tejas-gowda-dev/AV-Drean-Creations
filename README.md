# AV Dream Creations

A modern and responsive photography and videography website built using React and Vite. The website showcases wedding, pre-wedding, maternity, baby shoot, cinematic films, and event photography services with a clean and engaging user experience.

## Features

- Responsive design
- Modern UI/UX
- Image galleries
- Service showcase
- Contact section
- Fast performance with Vite
- Mobile-friendly layout

## Tech Stack

- React
- TypeScript / JavaScript
- Vite
- HTML5
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/Tejas-gowda-dev/AV-Drean-Creations.git
```

Navigate to the project folder:

```bash
cd AV-Drean-Creations
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

## Build for Production

```bash
npm run build
```
